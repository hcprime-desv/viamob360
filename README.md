# ViaMob360 — site público

Site da plataforma ViaMob360 (Next.js 15). Conteúdo gerido no painel ViaMob360 (Site público) e Chat com a Central ligado ao OmniChannel.

```bash
cp .env.local.example .env.local   # preencha Firebase e NEXT_PUBLIC_VIAMOB_PATH
npm install
npm run dev
```
